# H&M 고객 구매 패턴과 RFM 세분화

쇼핑몰에서 누가 자주 구매하고 많이 소비하는지 파악하고, 고객 그룹별 마케팅 전략을 검토한다. [H&M Kaggle 데이터](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/data)의 고객 정보, 거래 기록, 상품 정보, JPG 이미지를 사용한다.

전체 고객 목록에서 시드 42로 10,000명을 추출하고 해당 고객의 전체 관측 기간 거래를 보존했다. 실제 구매가 기록된 고객만 분석에 포함했다. 이미지 피처는 표본에 등장하고 JPG가 있는 상품 중 시드 42로 뽑은 500개에 대해서만 계산했다. 상품명 길이와 이미지 픽셀 평균·표준편차를 계산하고, 멤버십 그룹별 나이 결측치 대치와 IQR 이상치 탐지를 적용한다. RFM은 마지막 구매부터 기준일까지의 일수, 서로 다른 구매일 수, 원본 가격 합계로 계산한다. 구매일 수는 주문 횟수의 대리 지표이며, 가격은 데이터셋의 척도를 그대로 사용한다. 표본과 로컬 이미지의 범위는 결과 해석에 영향을 준다.

## 실행

1. [Kaggle 대회 규칙](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/rules)에 동의하고 `articles.csv`, `customers.csv`, `transactions_train.csv`, `images/`를 내려받아 `data/raw/`에 둔다. 전체 원본이나 위 기준으로 추출한 표본을 사용할 수 있다. 이미지 경로는 `images/<상품 ID 앞 세 자리>/<상품 ID>.jpg` 형식을 유지한다.
2. 저장소 루트에서 아래 명령을 실행한다.

   ```sh
   python -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python -m notebook
   ```

3. [분석 Notebook](notebooks/analysis_report.ipynb)을 열어 모든 셀을 순서대로 실행한다. Notebook에서 `DataAnalyzer`를 호출하고 분석 결과와 그래프를 출력한다.

## 분석 결과

2018-09-20부터 2020-09-22까지 구매 고객 9,925명의 거래 226,767행을 분석했다. 기본 병합 테이블은 13개 컬럼이며, 이미지 피처는 500개 상품에서 얻었다. 나이 결측은 고객 105명에서 대치 후 0명으로 줄었다. 거래 가격 10,095행(4.45%)이 IQR 범위를 벗어났다. RFM의 가격 합계에는 이 거래를 포함했다.

| 고객군 | 고객 수 | 고객 비중 | 평균 구매일 수 | 구매금액 비중 |
|---|---:|---:|---:|---:|
| VIP | 3,336 | 33.61% | 14.68 | 75.11% |
| Loyal | 453 | 4.56% | 3.99 | 1.23% |
| New | 166 | 1.67% | 1.00 | 0.27% |
| Churned | 4,960 | 49.97% | 2.69 | 21.12% |
| Active | 1,010 | 10.18% | 1.49 | 2.27% |

[Notebook](notebooks/analysis_report.ipynb)에서 가격 분포, IQR 전후 박스플롯, 상품군별 거래량, 상관행렬, 월별 합계와 세그먼트별 고객·구매금액 비중 차트를 확인할 수 있다. 분석 결과는 표본과 관측 기간에 한정된다.

## 비즈니스 인사이트

**VIP 고객 유지**

- **근거** · VIP는 고객의 33.61%지만 구매금액의 75.11%를 차지했다.
- **실행** · VIP에게 자주 구매하는 상품군의 신상품을 먼저 안내해 반복 구매를 유지한다.
- **검증** · 무작위 대조군과 90일 재구매율을 비교하고, 반품과 혜택 비용을 차감한 뒤에도 구매 기여가 늘었는지 확인한다.

**Loyal 고객의 구매 빈도 확대**

- **근거** · Loyal 고객의 평균 구매일은 3.99일로 VIP의 14.68일보다 적었다. 그룹 구분 자체에 구매일 수가 사용되므로 이 차이만으로 원인을 판단할 수 없다.
- **실행** · Loyal 고객에게 이전 구매 상품과 함께 사용할 수 있는 상품을 안내해 다음 구매를 유도한다.
- **검증** · 대조군을 두고 60일 내 서로 다른 구매일 수가 늘었는지 확인한다. 상품군별 재구매 주기와 반품 내역도 함께 비교한다.

**장기 미구매 고객 재활성화**

- **근거** · Churned는 4,960명(49.97%)이며 마지막 구매 이후 평균 413.7일이 지났다. 관측 기간에 구매 기록이 뜸한 그룹으로, 실제 이탈 여부는 알 수 없다.
- **실행** · 연락에 동의한 고객 중 과거 구매일 수가 많은 고객부터 소규모 재구매 캠페인을 시도한다.
- **검증** · 캠페인 발송 여부를 무작위로 나눠 30일 재구매율과 수신 거부율을 비교하고, 최근 구매 이력을 추가로 확보해 자연 복귀와 캠페인 효과를 구분한다.
